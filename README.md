# Aeloria

> Many roots. One home.

Aeloria is a story-led Minecraft Bedrock world and community project. The Discord server is called Aeloria and is the gateway where we find and organize the people who will build the lore world. The game server is called The Forgotten Ring, where their work becomes real.

The central aim of this repository is to build that Discord recruitment hub: make it welcoming, explain how people can contribute, preserve the Aeloria lore, and help recruits move from interest to meaningful work on The Forgotten Ring.

The project is built around a forgotten world, a drifting island, and a Promise no one can fully remember. Lore, architecture, server design, and community work should support one another without explaining away the mysteries.

## Project pillars

- **Canon before convenience** — record conflicts; do not silently resolve them.
- **Discovery before explanation** — let the world carry some of its own story.
- **Many roots, one home** — cultures differ; the Isle is shared.
- **Myth as structure, not decoration** — lore should shape places, routes, and play.

## Core foundation

- The Hunt drove the peoples from their homes.
- Refugees arrived at an Isle of mushroom soil and a silent tree later known as Ydrasil.
- The Promise was spoken before the Monolith in the Silent Chamber; its words were not preserved.
- The Isle changed after the Promise.
- The histories disagree. That disagreement is part of the world.
- The eight peoples in the wider lore are Fairies, Elves, Dwarves, Satyrs, Gnomes, Darklings, Sylphs, and Merfolk.
- Minecraft Bedrock seed: `-4021567764695071752`.

## Discord setup assistant

The bot in `tools/discord-rebuilder/` is deliberately conservative. It previews a manifest and can create missing roles, categories, and channels in one configured guild. It also has separately guarded reconciliation, content, role, lore, and owner-confirmed reset workflows. Review its manifest and exact preview output before running it against the live server.

See [`tools/discord-rebuilder/README.md`](tools/discord-rebuilder/README.md) for setup.

## Working status

The project is in its foundation and recruitment phase. Existing lore, maps, and Discord screenshots are being organized into a buildable plan. The first priorities are to keep canon legible, make contribution paths clear, and establish a small playable world milestone before expanding.
