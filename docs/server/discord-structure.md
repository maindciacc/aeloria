# Discord Structure and Community Plan

## Current status

The Discord server already has a clear conceptual structure. It is organized around a world-building, lore-first community rather than a generic gaming server.

## Existing categories and purpose

### The Gateway

Purpose: onboarding, rules, welcome, and member entry.

Suggested channels:
- `#welcome`
- `#begin-your-journey`
- `#rules`
- `#announcements`
- `#faq`
- `#server-road-map`
- `#roles-n-ranks`
- `#choose-your-roles`

### The Chronicles

Purpose: lore, history, worldbuilding, and emotional continuity.

Suggested channels:
- `#what-is-aeloria`
- `#the-promise`
- `#timeline-of-aeloria`
- `#territory-map`
- `#lore-library`

### The Commons

Purpose: general community interaction.

Suggested channels:
- `#general-chat`
- `#creations`
- `#screenshots`
- `#tavern-banter`
- `#ask-a-warden`

### The Guilds

Purpose: build groups, creative guilds, and function-based spaces.

Suggested channels:
- `#builders-hall`
- `#scribes-archive`
- `#artisan-guild`
- `#ideas-and-suggestions`

### The Mysteries

Purpose: conspiracy, theories, clues, fragments, and unresolved lore.

Suggested channels:
- `#theories`
- `#beneath-the-roots`
- `#the-lantern-child`
- `#forgotten-fragments`

### Voice channels

Suggested channels:
- The Tavern
- Builder Workshop
- Scribe's Study
- Artisan Corner
- AFK

## Role structure approach

The role hierarchy should reflect the community shape:

- Owners / top staff
- Council / lore authority
- Worldbuilder / server engineers
- Builders
- Scribes / lorekeepers
- Moderators
- Artist / designer roles
- Community roles
- New player / explorer roles

## Principle

The Discord should feel like a city of memory and craft, not a generic game hub. The community should feel like it is a living part of the world.
