# The Forgotten Ring Warden — Terms of Service

_Last updated: 2026-11-09_

These terms govern use of the Warden of the First Lock Discord bot for The Forgotten Ring and the Aeloria project.

## What the bot does

The Warden is a self-hosted project and community-management assistant. Depending on the server configuration, it can help maintain the configured Discord structure, publish project guidance, manage explicitly self-selectable roles, answer questions using local project material, and report configuration drift.

The bot is operated for the Aeloria project and is not an official Discord service.

## Acceptable use

Members must use the bot and the server lawfully and respectfully. Do not abuse commands, attempt to bypass role or channel restrictions, submit harmful content, or interfere with the bot or Discord services.

Self-selectable roles describe contribution interests. They do not grant staff authority, moderation powers, or access to private channels.

## Availability and changes

The bot is provided as-is. The maintainers may change, pause, or remove features, including role panels and local assistant features. Repository configuration and server permissions may change before a feature is enabled.

## Third-party services

Discord remains subject to Discord's own Terms of Service and Privacy Policy. Optional local Ollama and Obsidian integrations are controlled by the operator's machine and are not hosted by this bot.

## Contact

For project questions or corrections, use the Aeloria repository issue tracker or contact the project maintainers through the configured Discord server.

## Acceptance

Using the Warden means you agree to use it consistently with these terms and the server rules. If you do not agree, do not use the bot's commands or role panel.
